### Dependency measurements (WSL, GCC 11, -O2)

| Metric | before | after | delta |
|---|---:|---:|---:|
| headers pulled in by the IO header | 333 | 270 | -19% |
| preprocessed lines | 132,034 | 93,223 | **-29.5%** |
| leaf TU compile time (median of 3) | 2.23 s | 1.25 s | **-44%** |
| `models` library clean build | 18.6 s | 19.2 s | within noise |

The `models` library itself shows no measurable change: its translation units
already pull MNN / TensorRT / ONNX Runtime headers, which dwarf OpenCV. The win
is concentrated in translation units that only need the IO types. Splitting the
file buys ownership isolation now (one task's IO change no longer touches a
254-line monolith); the incremental-build payoff appears as call sites migrate
off the aggregate header.
