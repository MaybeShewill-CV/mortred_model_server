The migration is deliberately partial. The text encoder keeps its hand-written
int32 token packing (ImagePipeline is image-only) and the dual-session
orchestration stays as-is, because that is what phase 7's multi-session
template is for. OutputReader is used without .finite() so the validation is
exactly as strict as the validated_f32_named_output call it replaces - adding
the finite check would be a behaviour change, not a substitution.
