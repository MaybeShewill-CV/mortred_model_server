### Deferred: the enhancement family

real_esrgan accepts 3- or 4-channel input and converts BGRA/BGR to RGB before
normalising. ImagePipeline has no bgra_to_rgb() and its bgr_to_rgb() requires
exactly three channels, so migrating it needs a deliberate toolkit addition
rather than a substitution.

An attempted migration silently dropped that conversion and still passed the
golden case - because the test input (wolf_gray.jpg) is grayscale, where the
BGR/RGB swap is a no-op. Neither the golden hash nor the test can catch this
regression, which is exactly why the family is deferred instead of shipped.
enlightengan (dual src + gray tensors) and attentivegan are deferred for the
same reason: they need individual handling, not a pattern substitution.
