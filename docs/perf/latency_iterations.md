# YOLOV8 端到端链路耗时迭代记录（C=1 / raw 传输）

目标：http_infer_rps.py 实测 **C=1 raw P50 ≤ 13ms** 且 **C=16 raw RPS ≥ 120**（P50 用 C=1 测量，RPS 用饱和并发测量——C=1 闭环下 rps=1/延迟，两者无法在同一并发下同时满足）。
方法：每轮迭代 = 单项改造 → 重编译 → 重启 YOLOV8 → golden 数值对比 → C=1×3 轮(60s+5s warmup, raw) + C=16×1 轮(60s+5s, raw) 埋点实测 → 与历史对比落盘本文件。
环境：RTX 2070 SUPER / TensorRT 10.3 / WSL2 / 埋点分支 `perf/stage-timing`（`/tmp/mortred_stage_timing` 开关）。
输入：bus.jpg（810×1080 JPEG，487KB，5 个检测框，golden 基准 `/tmp/golden_pre_w1.json`）。

## 迭代 1：W1 融合预处理核（letterbox_bgr_f32_nchw）

改动：`model_runtime.{h,cpp}` 新增 `letterbox_bgr_f32_nchw`（resize 后单遍平面写入，消除 cvtColor/全图 pad/convertTo/scale/CHW 双拷贝五个全图中间体，数值逐比特等价：resize 通道无关可与 BGR→RGB 交换次序，pad 与像素走同一 `(float)px*(1/255f)` 单乘）；`yolov8_detector.inl` preprocess 优先融合路径，旧五步链保留为回退。

**精度门禁**：bus.jpg golden 对比——5 框→5 框，全部字段差异 `0.000e+00`（逐比特等价，与设计一致）。
