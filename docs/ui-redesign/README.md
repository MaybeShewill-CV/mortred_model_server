# Supervisor 控制台 — Lumen 产品化重设计（UI Redesign）

> 本目录记录 Supervisor Web 控制台从「磷光终端风」到「Lumen 产品级控制台」的完整重设计过程。
> 触发原因：旧版（phosphor 风格）在七维度评审中加权仅 **6.0/10**，同事普遍反馈「不好看」。
> 退出条件（用户目标）：七维度全部 ≥ 9.0，加权总分 > 9.5，每轮留档前后截图。
>
> 评审方法：mock 数据（12 模型 / GPU 采样 / 日志 / 指标流）驱动真实浏览器渲染，
> 由独立视觉模型按维度盲评 + 交互功能烟测（palette / 主题切换 / 过滤 / 导航）。

## 与目标的差距声明

七维度全部 ≥ 9.0 ✅ 已达成；加权 9.27，距离 9.5 目标还差 0.23。
评审模型对静态截图的稳定输出上限在 9.2–9.4 区间（它对 9+ 的定义是
「接近 Linear/Vercel 官网级别」）。继续提分的现实路径不再是静态视觉，
而是动态体验（数字 tween、环动画、面板级联入场——均已实现但截图无法
承载）与真实数据密度。详见 [R5 文档](R5-hero-and-final.md) 的结论章节。

## 工程约束（全程保持）

- 三文件结构不变：`index.html` / `style.css` / `app.js`（C++ 静态白名单无需扩容）
- 零依赖、零构建、零 webfont；内联 SVG 图标体系（约 40 个 lucide 风格图标）
- 功能全量保留：token 对话框、⌘K 命令面板、j/k 导航、日志 follow/filter、
  批量推理 bench、全部结果可视化器、断链 overlay、reduced-motion、aria
