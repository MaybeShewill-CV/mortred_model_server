## 行为变化
worker 数扫描的并发是该点 worker 数的两倍，warmup 5 秒，测量时长用传入的 60 秒。该测点的套接字超时改为 `duration + 5 + 45` 秒。`run_one_point` 用 `server_uri` 读两只直方图，空的 before 按 count 0 进入现有差值。解码投票仍是 10 秒和原来的 16 张网格。压测连接在读完响应后由客户端结束，单次请求保持 keep-alive，避免监听端口进入 TIME_WAIT。`wait_port_free` 仍是 15 秒。

`scripts/coverage_http_report.py` 按九个 id 串行 prepare、仓库外临时 pack、`calibrate --write-pack --duration 60s`、只部署这一份 pack、再对 gateway 做官方 `--raw` 压测。一行通过字段检查后立刻写入 `docs/perf/coverage_set_http_rps.md`。进程 worker 数只取压测完成后、进程仍在时的两只 gauge 之和。pphuman_mobile 使用 `face_w_mask.jpg`。realesrgan 使用 `logs/p2-11-realesrgan-256.jpg`。
