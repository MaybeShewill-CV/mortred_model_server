## 不适用
- 未知 catalog id、错误 id、未就绪模型：本条验收是覆盖集九个 id 的清单，不测目录外 id。
- 空输入、极端尺寸、通道或色彩不符：本条不改预处理；指定 JPEG 与 realesrgan 256×256 已在验收 1 判定。
- 坐标、mask、类别分数的形状和值域：本条只读取成功 RPS 与顶层 `server_time_ms`，不改推理结果结构。
- 超时和参数缺失的错误码矩阵：行内已有不含 429 的错误率和单独的 429 次数；不另开网关错误码表。
- MNN、ONNX Runtime 与 TensorRT 的同输入对照：本条只记录 static shape、batch=1 的 TensorRT HTTP 结果。
- 已有 golden 与 CI 是否重跑：本条 diff 不改 golden；九 id 全量压测不作为 QA 通过条件。
- yolov8s 与 libface 同时 ready：验收 5 写明不作为本条通过条件。
