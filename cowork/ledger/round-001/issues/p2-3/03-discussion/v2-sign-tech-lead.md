# 第3步确认

- 问题: P2-3
- 方案版本: v2
- 结论: 同意
- 条件: 无
- 理由: v2 把上一版两条确认条件写进了同一次启动的判定，自测按这个判定执行。libface 仍先关掉 fd 3 及以上；跟踪每次重新打开日志，并在原来的 `execve` 之前记下 `inh=closed` 的绝对路径终点。没有这行终点，或该 pid 只出现在 `exec` 之后，不通过。终点之前不得出现 `prctl`、`execvp`、`setenv`。探测有输出时，另一个直接子进程走同一段窗口，不检查路径是否以 `/nvidia-smi` 结尾。改动停在拉起子进程的 `prctl` 和两处 `nvidia-smi` 的 `execvp`；父进程死亡信号仍是子进程里、关 fd 之后的 `SIGINT`。catalog 仍是一个 id 一个进程。
