## 逐条
| id | 表决 | 理由 |
| --- | --- | --- |
| C1 | 保留 | 增强交付现场排障能看到：形状错与空输出若同为 `model output empty`，和契约失败码混在一起，会把问题指错方向；改完后应用 `status_str`/同口径指标能黑盒区分形状契约失败与真·空输出，值得进 P1。 |
| C2 | 删除 | 只改日志里的通用名，不改变客户是否能交付、也不改变一次失败能否定位到哪台 catalog；进程/指标已带模型身份，达不到 P0/P1。 |
| C3 | 删除 | modnet、bisenetv2 已有无权重假 tensor 契约，整条「三模型都缺」不成立；resnet 单独补测不构成交付阻断；深度契约已关闭，不得借壳重开。 |
| C4 | 保留 | 与已关闭的「drain 超时本身」不同：超时后仍拆成员，挂死停服可能变成异常退出而非「打完 timeout 日志后等外层 SIGKILL」；运维可黑盒对照停服终态，值得作为残余 P1。 |

## 不同意的条目
- C3：不得按「modnet / bisenetv2 / resnet 都没有无权重契约」开单；前两者已有，深度假 tensor 已关闭，禁止借本条重开 DepthAnything。
