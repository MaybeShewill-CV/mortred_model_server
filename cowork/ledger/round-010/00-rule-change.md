## 2026-10-09 范围

最高标准不再收成一条旗舰，也不允许用「边界写明不做」把模型移出数值门。

分类、目标检测、人脸检测、分割、OCR、图像增强、特征点检测、feature embedding、matting、深度估计的每一个 HTTP catalog id 都要满足 H1 至 H4。YOLOv8 含 `yolov8n`、`yolov8s`、`yolov8l`、`yolov8x`。`yolov8s` 已关闭的 IoU 门只覆盖 `yolov8s`。人脸检测的 id 是 `libface` 与 `centerface`，框的规则与目标检测相同。

SAM、diffusion、CLIP、LightGlue 不在该表。OCR 识别器仍不计毛病。`dbnet` 要达到最高标准。
