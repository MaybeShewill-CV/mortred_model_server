## 缺陷

无。

白盒核对成立：`classify_extractor_outputs` 与 `classify_matcher_outputs` 在返回前调用 `require_finite_f32`；`extract_feature_points`、`match_feature_points` 先调用这两个函数，分数阈值比较在其后。`encode_image` 与 `encode_text` 在 session 成功后都调用 `classify_embedding_output`，`normalize_embedding` 在 `texts2img` / `imgs2text` 里更后。失败路径先 `embedding.clear()`。缺名与空文本断言仍是 `MODEL_EMPTY_OUTPUT`。`normalize_embedding` 对 `norm <= 1e-12`（含有限全零）仍返回失败，调用方仍是 `MODEL_EMPTY_OUTPUT`。

## 不适用

- 正确 catalog id、错误 id、未就绪模型：本条不改 catalog、HTTP 或进程模型。
- 空输入、极端尺寸、通道或色彩：预处理与秩、形状、短 buffer 不在冻结范围。
- 检测输出的坐标、mask、类别分数：本条只覆盖 LightGlue 与 CLIP 的 dtype / NaN / +Inf。
- 超时与参数缺失：验收命令不启动 gateway 或 supervisor，也不加载权重。
- 多后端数值一致：方案不要求同一输入跨后端比较。
- golden 与全量 CI：本条不改 golden；指定 ctest 已覆盖这两个套件。本条通过不作为 D-5、D-6 或其他已关闭 id 的关闭证据。
