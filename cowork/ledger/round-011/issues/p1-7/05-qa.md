## 不适用
- 正确 catalog id、错误 id、未就绪模型：本项不启动模型进程，不覆盖推理路由的 id 解析和未就绪状态。
- 空输入、极端尺寸、通道或色彩：示例是长度不超过 64 的占位字符串，不解码图像，也不跑预处理。
- 输出结构、坐标、mask、类别分数的真实值域：本项只核对 OpenAPI 示例的形状、值域上限和 schema，不比较 golden 数值。
- 错误码、超时、参数缺失：方案只要求请求示例和 200 示例，状态码与错误响应不在本次改动面。
- 后端一致：方案不要求同一输入在 CPU 与 TensorRT 上的可比较结果。
- 已有 golden 与 CI：本次 diff 不改 `test/golden` 和数值门槛。`.github/workflows/ci.yml` 仍调用 `python3 scripts/check_consistency.py` 与 `python3 scripts/gen_openapi.py --check`。`image/png`、`image/jpeg`、`application/octet-stream` 的 example 数量为 0。`docs/api-contract.md` 的 7 个人读片段不作为这 39 个 path 的示例。

## 残余风险
示例是短占位，不能当作一次真实推理的数值结果。`EnvelopeData` 的 schema 只有 `nullable`，`msocrnet` 与三个 DINOv2 的字段口径由 `gen_openapi.py --check` 另判。Windows 检出把 `test/golden/mobilenetv2_classification.json` 写成 CRLF 时，golden 原始字节哈希与基线不同；本次在 LF blob 上 `check_consistency.py` 退出码为 0，该文件已 checkout，未提交。表外 9 个 path 没有请求 example，两条自测命令仍退出 0。
