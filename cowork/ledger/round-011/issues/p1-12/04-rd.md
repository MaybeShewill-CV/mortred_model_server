这 9 条的实测差距：

- `mobilenetv2`、`resnet`、`densenet`：`score mismatch at`，分数绝对差到 1～4，超过 `1e-3`。尾部黄金分数约 `1e-4`，TensorRT 输出是 O(1)。
- `yolov5l`：`detection count changed for yolov5_detection`，预测 5 框，黄金 7 框。
- `yolov6s`：`detection count changed for yolov6_detection`，预测 7 框，黄金 5 框。
- `yolov7`：分数差约 0.07～0.38，超过 `0.01`。
- `libface`：关键点距离约 5.6～25.8，超过 `3.0`，同时有分数差超过 `0.01`。
- `enlightengan`：`fingerprint drift for enlightengan_enhancement`，均值绝对差约 7.00，超过 `1.0`。
- `dinov2_vitb14`：`embedding cosine similarity low for dinov2_feature_embedding`，余弦约 0.126，低于 `0.999`。

影响：这 9 个 id 的产品 engine 已经按产品 toml 在 GPU 上跑过，比较函数和黄金茎名与对应 CPU 用例相同，但过不了该 CPU 规则。其余自测命令与方案一致。

## 行为变化

`MORTRED_HAS_TRT` 下新增套件 `TrtProductGolden`，38 个测试名是方案名单里的 catalog id。每条加载该 id 的产品 toml，只剥 `../`，`type=tensorrt`、`device=gpu`，向标准输出打一行 `product toml ...`，再 `init`、读图、`run`、按该家族规则比较。缺 engine 仍走 `weights not available`。已有 CPU 用例的 19 条在 `MORTRED_UPDATE_GOLDEN=1` 时于读图和 `init` 之前失败，文案含 `refusing to overwrite cpu golden`。没有 CPU 用例的 id 黄金茎名是 `trt_<id>`，只在该环境变量下由测试进程写出后跳过，跳过文案含 `golden updated`。没有 CPU 用例的检测、embedding、深度比较会在失败输出里带上 `0.5` / `0.01` / `class_id`、`0.999`、`0.02`。深度只比较全分辨率 `depth_map`。

推理热路径没有改。比较在测试进程拿到模型输出之后进行，现有 `init` / `run` 够用。
