- 针对版本: v1

## 逐条
| id | 评审 | 理由 |
| --- | --- | --- |
| P2-12 | 拆开 | 按教程启动的人打开英文教程就能核对 `--model`。这一条同时写了覆盖集里的 `mobilenetv2`、`superpoint`，以及覆盖集外的 `yolov5l`、`bisenetv2`、`attentive_gan`。拆成覆盖集这两条；后三个 id 移出队列。中文教程并入留下的这一条。 |
| P2-13 | 合并 | 与 P2-12 是同一类：中文教程按其中一条启动同样得到 `unknown --model`。并入 P2-12 拆开后的覆盖集两条，一次打开两份教程即可核对。 |
| P2-14 | 保留 | 按教程改 worker 数的人，打开教程就能核对那一句：仓库自带配置的 `worker_nums` 保持 1，校准出的数值写在机器 pack。中文同句并入后，仍是一次阅读。 |
| P2-15 | 合并 | 与 P2-14 是同一句的中文。并成一条，一次打开两份教程即可核对。 |
| P2-16 | 保留 | 按中文「添加新服务」往分类家族加示例的人，只打开这一份就能核对 `model_section`、`--model`、`model=` 和 family 都是 `densenet`。英文示例不在本条。 |
| P2-17 | 保留 | 业务后端对照公共响应示例和 `docs/openapi.json` 时，打开契约就能核对 `model.name` 是 `mobilenetv2`。中文同例并入后，仍是一次阅读。 |
| P2-18 | 合并 | 与 P2-17 是同一处示例的中文。并成一条，一次打开两份契约即可核对。 |
| P2-19 | 拆开 | 读 gateway `/metrics` 的人，要在五段 p50 之和大于模型 `server_time_ms` p50 的一半时，第 4097 次成功后仍能看到 `mortred_gateway_stage_dominant`。这一句留下。`stage` 必须是五段里 p50 最大的名字这一句，只读这一次 `/metrics` 对不齐，删除。 |
| P2-20 | 拆开 | 看 `inference-paths` 日志的人，一次只能验收一件事。只跑当前四个 ONNX 用例时日志里没有 `TRT_PROOF=yes`，看这一次日志即可，引擎步骤被跳过或只写出引擎文件都归在这一句。日志出现 `TRT_PROOF=yes` 时，同一次 gtest XML 里要有产品 `type=tensorrt` 且 `skipped=0`，那是另一次运行。 |

## 不同意的条目
- P2-12：`yolov5l`、`bisenetv2`、`attentive_gan` 三条启动命令是范围外，不跟覆盖集的两条绑在同一次验收里。
- P2-13：中文教程与 P2-12 是同一类，并成一条。
- P2-15：中文 worker 数那一句与 P2-14 是同一类，并成一条。
- P2-18：中文公共响应示例与 P2-17 是同一类，并成一条。
- P2-19：`stage` 等于 p50 最大名字这一句，一次读取 `/metrics` 判定不了，删除。
- P2-20：没有 `TRT_PROOF=yes`，和出现该行时 XML 里有产品 TensorRT 用例，要分成两次验收。
